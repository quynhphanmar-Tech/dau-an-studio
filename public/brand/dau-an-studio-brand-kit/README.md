# Dấu Ấn Studio — Brand Kit 1.1 Approved Master

Nền tảng nhận diện chính thức theo concept **Imprint Cocoon — Bản sắc được khai mở**.

## Quy tắc ưu tiên tuyệt đối

`approved-master-board.png` là bản duyệt chuẩn. Logo phải được lấy từ asset trong bộ này, không redraw, không dùng AI/code tạo hình gần giống và không đơn giản hoá đường vân.

## Chọn đúng asset

| Nhu cầu | File nên dùng |
| --- | --- |
| Hero, cover, Brand DNA, milestone | `logo-mark-primary.svg` |
| Header, navigation, avatar nhỏ | `logo-mark-compact.svg` |
| iOS/Android/PWA | `app-icon.svg` hoặc PNG đúng kích thước |
| Website/landing page | `logo-lockup-horizontal.svg` |
| Token triển khai frontend | `brand-tokens.css` |
| Luật sử dụng | `brand-guideline.md` |
| Bảng duyệt nhanh | `logo-system-board.png` |
| Bản chuẩn đối chiếu | `approved-master-board.png` |

## Quy tắc triển khai nhanh

- Display/wordmark: Playfair Display 400/500.
- UI và tiếng Việt: Be Vietnam Pro 400/500.
- Primary Art Mark dùng từ 72px; Compact Digital Mark dùng từ 24px nhưng vẫn giữ nguyên artwork.
- Nền chính `#F7F7F5`; chữ `#111111`; CTA `#315CFF`; `#FF5A47` chỉ là điểm nhấn nhỏ.
- Không thêm gradient, shadow, shield, target, hình bướm hoặc chi tiết sinh trắc học.
- Trước khi in hay nộp đăng ký nhãn hiệu, chuyển wordmark thành outline và kiểm tra dấu tiếng Việt thủ công.

## Cấu trúc concept

`Bản sắc → Khai mở → Chuyển hoá → Ảnh hưởng`

Dấu vân tay biểu đạt chuyên môn riêng. Chiếc kén biểu đạt quá trình nhìn vào bên trong và tái cấu trúc. Khoảng mở hướng lên phải biểu đạt sự xuất hiện, cơ hội và ảnh hưởng.
